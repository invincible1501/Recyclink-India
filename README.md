# RecycLink India ♻️

### Fair Value. Safe Recycling. Stronger Communities.

RecycLink India is a digital platform designed to connect informal e-waste collectors with verified recyclers through a simple, accessible and traceable digital workflow.

The platform helps collectors create e-waste lots, classify materials, view indicative prices, discover verified recyclers, record handovers and maintain digital transaction records.

---

## 🚀 Project Overview

Informal e-waste collectors play an important role in collecting and aggregating electronic waste, but often face challenges such as:

- Uncertainty about material prices
- Limited access to verified recyclers
- Difficulty comparing recycling opportunities
- Lack of digital transaction records
- Limited traceability after material handover
- Exposure to unsafe e-waste handling practices

RecycLink India provides a software-based interface to address these challenges.

---

## ✨ Key Features

### 📦 E-Waste Lot Creation
- Create a new e-waste lot
- Select material category
- Enter approximate weight
- Record material condition
- Capture an e-waste photograph
- Generate a digital lot identity

### 🧠 AI-Assisted Classification
- Material classification interface
- Confidence indication
- Collector-controlled category correction
- Manual classification fallback
- Classification-linked value estimation

### 💰 Price Board
Indicative price ranges are provided for different e-waste categories:

| Material | Indicative Price |
|---|---:|
| Printed Circuit Board | ₹180–220/kg |
| Copper Cable | ₹430–520/kg |
| Mixed E-Waste | ₹65–95/kg |
| Computer / Laptop | ₹70–110/kg |
| Mobile Phone Scrap | ₹280–360/kg |

> Prices shown in this prototype are illustrative and intended for demonstration.

### ♻️ Verified Recycler Matching
- Recycler discovery
- Distance information
- Material compatibility
- Indicative offer information
- Recycler selection

### 🔐 Digital Handover
- Unique lot identification
- QR-based handover interface
- Final weight recording
- Final value recording
- Payment confirmation

### 📜 Digital E-Waste Passport
Each lot can have a digital record containing:

- Lot ID
- Material category
- Initial weight
- Final weight
- Final value
- Payment status
- Transaction timeline

### 📊 Earnings & Analytics
- Transaction history
- Earnings tracking
- Material mix
- Collection statistics
- Monthly earnings visualization

### 🛡️ Safety Guidance
The platform provides visual safety guidance related to:

- Wire burning
- Acid processing
- Damaged batteries
- Protective equipment
- Verified recycling

### 📱 Responsive Interface
The prototype is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices

---

## 🖥️ Prototype

The current prototype is implemented as a single HTML application containing:

- HTML
- CSS
- JavaScript

No external backend is required to run the current demonstration prototype.
